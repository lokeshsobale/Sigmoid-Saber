# PowerPoint presentation description

**Presentation title:** Master Yoda vs. Kuro — A Linear Regression Boss Battle

**Description:**

This presentation introduces an interactive educational game developed in Python using Tkinter to teach the fundamentals of Linear Regression. The game is organised into four themed worlds: data collection and variables, slope and intercept, residuals and Mean Squared Error (MSE), and extrapolation. Players practise fitting a linear model, compare their results with the Ordinary Least Squares (OLS) solution, and observe how batch Gradient Descent learns model parameters. The presentation also explains the gameplay design, player feedback and scoring, learning check-up, local progress history, and the technologies used to build the application.
